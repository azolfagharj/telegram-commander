    Функция¶

    То, что запускается при нажатии кнопки кнопка. А функция принимает некоторые параметры и превращает их в команду оболочки.

    Есть два вида:

    • Встроенные функции поставляются вместе с программой (command, script). Вы не создайте их.
    • Пользовательские функции — это дополнительные функции, которые вы определяете в виде файлов YAML в function_directory.

    Когда вы нажимаете кнопку, бот ищет функцию и заполняет значения из кнопку и запускает результат в файле оболочка.

    Кнопка, использующая встроенную функцию command

    Uptime button
    - name: Uptime
  type: button
  function: command
  command: "uptime"
