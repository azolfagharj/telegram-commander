# Contributing to Telegram Commander

Thank you for your interest in Telegram Commander! 🚀

Telegram Commander is still in its early stage, and we're gradually building the project's community and contribution process.

For now, the best way to contribute is to **report bugs, share feedback, ask questions, and suggest ideas**.

## How to contribute

### 🐛 Found a bug?

Please report confirmed bugs through [GitHub Issues](https://github.com/azolfagharj/telegram-commander/issues).

When reporting a bug, include as much useful information as possible, such as:

* Telegram Commander version
* Operating system and relevant environment details
* What you expected to happen
* What actually happened
* Steps to reproduce the problem
* Relevant logs or error messages

Please search existing issues before opening a new one.

### 💡 Have a feature idea?

Share it in [Ideas & Feature Requests](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests).

This gives the community a chance to discuss the idea before it becomes a concrete implementation task.

### 🙏 Need help?

For questions about installation, configuration, usage, or troubleshooting, use [Questions & Help](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help).

### 💬 Have general feedback?

Use [General](https://github.com/azolfagharj/telegram-commander/discussions/categories/general) for general feedback and project-related conversations.

### 🙌 Built something with Telegram Commander?

We'd love to see it!

Share your setup, integrations, automation, or other interesting use cases in [Show & Tell](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell).

## Pull requests

**Pull requests are currently closed.**

Telegram Commander is still establishing its development and contribution workflow. As the project grows, we may gradually open pull requests to the community.

If you would like to contribute code, please watch the repository and check the Discussions and announcements for future updates.

## 🔐 Security vulnerabilities

Please **do not** report security vulnerabilities through public Issues or Discussions.

Use the repository's [Security tab](https://github.com/azolfagharj/telegram-commander/security) to privately report a vulnerability.

For more information about our security policy, see [SECURITY.md](SECURITY.md).

## Before contributing

Before opening an Issue or Discussion:

1. Search existing Issues and Discussions.
2. Check the documentation and README.
3. Choose the appropriate place for your report, question, or idea.

This helps keep the project organized and makes it easier for everyone to find useful information.

Thank you for helping make Telegram Commander better! ❤️
