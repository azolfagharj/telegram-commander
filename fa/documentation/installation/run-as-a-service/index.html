    اجرا به‌صورت سرویس¶

    این صفحه اجرای Telegram Commander به‌صورت سرویس systemd را توضیح می‌دهد. برای نخستین اجرای گام‌به‌گام در ترمینال، اجرا در CLI را ببینید.

    systemd (root)¶

    فایل واحد را خودتان بسازید، برای نمونه /etc/systemd/system/telegram-commander.service:

    این نمونه همهٔ دکمه‌ها را با دسترسی root اجرا می‌کند

    /etc/systemd/system/telegram-commander.service
    [Unit]
Description=telegram-commander Telegram bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/path/to/telegram-commander run --config /path/to/configfile.yaml
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

    چون خط User= وجود ندارد، سرویس با root شروع می‌شود و همهٔ فرمان‌های منو روی دستگاه دسترسی کامل دارند. اگر دکمه‌ها به این سطح از دسترسی نیاز ندارند، User=someone را به بخش [Service] بیفزایید.

    مسیرهای جایگزین را عوض کنید، سپس:

    بارگذاری و شروع سرویس

    فعال‌سازی، شروع و مشاهدهٔ سرویس
    sudo systemctl daemon-reload
sudo systemctl enable --now telegram-commander
sudo systemctl status telegram-commander
sudo journalctl -u telegram-commander -f

    تغییر پیکربندی به راه‌اندازی مجدد نیاز دارد

    سرویس ربات را روشن نگه می‌دارد، اما فایل پیکربندی را یک‌بار هنگام شروع می‌خواند. پس از ویرایش آن، sudo systemctl restart telegram-commander را اجرا کنید.
