# :material-lan-disconnect: نحوهٔ اتصال ربات

ربات از داخل به تلگرام متصل می‌شود. نیازی نیست پورتی روی سرور باز کنید.

!!! tip "چیزی در معرض اینترنت قرار نمی‌گیرد"

    چون اتصال همیشه رو به بیرون است، پنل وبی برای ایمن‌سازی، قاعدهٔ ورودی
    فایروال برای افزودن یا نشانی عمومی برای پیدا شدن وجود ندارد. دستگاه
    می‌تواند پشت روتر خانگی یا فایروالی سخت‌گیر باشد و ربات همچنان کار کند.

اگر تلگرام در شبکهٔ شما مسدود است، زیر `telegram` در
[فایل پیکربندی](config-file.md) یک پراکسی تنظیم کنید.

## پیکربندی

برای `api`، `proxy` و `insecure` در تنظیمات تلگرام،
[پیکربندی ← telegram](../configuration.md#telegram) را ببینید.

## مرتبط

- [کاربران مجاز](allowed-users.md) — چه کسانی می‌توانند از ربات استفاده کنند
- [CLI ← run](../cli.md#run) — اجرای ربات در پیش‌زمینه
- [اجرا به‌صورت سرویس](../installation/run-as-a-service.md) — روشن نگه داشتن ربات
