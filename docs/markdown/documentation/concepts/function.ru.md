# :material-function: Функция

То, что запускается при нажатии кнопки [кнопка](button.md). А
[функция](function.md) принимает некоторые [параметры](parameter.md) и
превращает их в команду оболочки.

Есть два вида:

- **Встроенные функции** поставляются вместе с программой (`command`, `script`).
  Вы не создайте их.
- **Пользовательские функции** — это дополнительные функции, которые вы
  определяете в виде файлов YAML в `function_directory`.

Когда вы нажимаете кнопку, бот ищет функцию и заполняет значения из кнопку и
запускает результат в файле [оболочка](shell.md).

!!! example "Кнопка, использующая встроенную функцию `command`"

    ```yaml title="Uptime button"
    - name: Uptime
      type: button
      function: command
      command: "uptime"
    ```
