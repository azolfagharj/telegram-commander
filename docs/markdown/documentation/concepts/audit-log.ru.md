# :material-history: Журнал аудита

Отдельный поток журнала, в котором записывается каждая выполненная команда: кто
ее выполнил, что
[кнопка](button.md), код выхода и сколько времени это заняло. Настроено под
`logging` в вашем [конфигурационном файле ](config-file.md).

Это запись, которую вы проверите позже, когда захотите узнать, кто перезапустил
сервис в три часа ночи, или действительно ли вчерашняя кнопка резервного
копирования закончил. Поскольку это отдельный поток, вы можете оставить его
после обычного журнал приложения удален.

Каждый прогон добавляет одну строчку, а между ними отвечают на четыре вопроса:

| Вопрос | О чем говорит вам эта линия |
|---|---|
| ВОЗ? | Аккаунт Telegram, который нажал кнопку |
| Что? | Кнопка, которую они использовали |
| Это сработало? | Код завершения, возвращенный командой |
| Сколько? | Время, необходимое команде для завершения |

!!! example "Запись журнала аудита в отдельный файл"

    ```yaml title="logging section of config.yaml"
    logging:
      logs:
        audit:
          level: info
          format: json
          output:
            - output: file
              file: /var/log/telegram-commander/audit.log
    ```
