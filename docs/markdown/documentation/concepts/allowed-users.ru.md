# :material-shield-lock: Разрешенные пользователи

Список аккаунтов Telegram, которым разрешено использовать бота, по цифре
`user_id` или `@username`. Всем остальным отказывают.

Неавторизованные пользователи получают сообщение со своими `user_id` и
`username`, поэтому они могут попросить администратора предоставить доступ.
Таким же образом вы сможете найти свой собственный идентификатор. в первый раз —
см. [Запуск в CLI → Шаг
5](../installation/download-and-run.md#step-5-find-your-user-id-if-needed).

Это сообщение также служит способом добавления кого-либо. Попросите нового
человека отправить боту любое сообщение, попросите его скопировать
идентификатор, с которым он отвечает, и добавить этот идентификатор в
`allowed_users` и перезапустите бота. В следующий раз, когда они напишут, они
получат меню. вместо отказа.

!!! warning "Все в списке используют одно и то же меню"

    Разрешения для каждого пользователя отсутствуют. Любой, кого вы добавите,
    сможет нажать любую кнопку, которую вы определены, поэтому сохраните список
    людей, которым вы доверяете саму машину.

!!! example "Двум аккаунтам разрешено использовать бота"

    ```yaml title="telegram section of config.yaml"
    telegram:
      allowed_users:
        - "123456789"
        - "@alice"
    ```
