# :material-lan-disconnect: Как подключается бот

Бот подключается к Telegram. Вы не открываете порт на своем сервере.

!!! tip "Нечего выставлять в Интернете"

    Поскольку соединение всегда идет только наружу, веб-панели для этого нет.
    безопасно, нет необходимости добавлять правила брандмауэра для входящего
    трафика и нет публичного адреса для кого-либо. найти. Машина может
    находиться за домашним маршрутизатором или строгим брандмауэром и бот все
    еще работает.

Если Telegram заблокирован в вашей сети, установите прокси под `telegram` в
вашем
[файл конфигурации](config-file.md).

## Конфигурация
