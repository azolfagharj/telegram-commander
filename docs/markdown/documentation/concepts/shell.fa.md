# :material-console-line: Shell

برنامه‌ای که فرمان شما را اجرا می‌کند و به‌طور پیش‌فرض `/bin/bash` است.
فرمان‌ها به‌شکل `bash -c "your command"` اجرا می‌شوند؛ بنابراین pipe و
تغییر مسیر کار می‌کنند.

می‌توانید شِل را با کلید `shell` در [فایل پیکربندی](config-file.md) به‌صورت
سراسری تغییر دهید.

!!! example "انتخاب شِل"

    ```yaml title="ریشهٔ config.yaml"
    shell: /bin/bash
    ```

هر [تابع](function.md) فرمان خود را از طریق همین شِل اجرا می‌کند.

## پیکربندی

برای فیلد `shell` و گزینه‌های ریشهٔ مرتبط،
[پیکربندی ← فیلدهای ریشه](../configuration.md#root-fields) را ببینید.

## مرتبط

- [تابع](function.md) — فرمانی را تولید می‌کند که شِل اجرا می‌کند
- [فایل پیکربندی](config-file.md) — محل تنظیم `shell`
