# :material-console-line: Оболочка

Программа, выполняющая вашу команду, по умолчанию `/bin/bash`. Команды
выполняются как `bash -c "your command"`, поэтому каналы и перенаправления
работают.

Вы можете изменить оболочку глобально с помощью ключа `shell` в вашем
[файл конфигурации](config-file.md).

!!! example "Выбор оболочки"

    ```yaml title="Root of config.yaml"
    shell: /bin/bash
    ```

Каждая [функция](function.md) выполняет свою команду через эту оболочку.

## Конфигурация

Информацию о поле `shell` и связанных с ним корневых параметрах см.
[Конфигурация → Корневые поля](../configuration.md#root-fields).

## Похожие

- [Функция](function.md) — создает команду, которую запускает оболочка.
- [Конфигурационный файл](config-file.md) — где установлен `shell`
