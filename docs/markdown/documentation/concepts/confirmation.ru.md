# :material-help-circle-outline: Подтверждение { #confirmation }

Необязательный вопрос «Вы уверены?» шаг перед запуском [кнопка](button.md),
включен с `confirm: true`. Полезен для разрушительных действий.

Бот спрашивает (`Confirm: … ?`) с Да/Отмена плюс Домой (и Назад, когда вы
находятся внутри категории). Когда команда «Выполнить» включена, эта кнопка
остается на экран подтверждения тоже. Ничего не запустится, пока вы не нажмете
«Да»; Отмена, Домой и Назад все оставьте команду в покое.

Срок действия приглашения истекает через некоторое время (по умолчанию 5 минут).
Измените его с помощью `confirm_ttl` в вашем [конфигурационном файле
](config-file.md). Если срок его действия истек, коснитесь значка нажмите кнопку
еще раз, чтобы получить новое приглашение.

!!! warning "Используй его для всего, что нельзя отменить"

    Клавиша меню на телефоне находится в одном касании, и каждый может
    использовать бота. видит то же меню. Поместите `confirm: true` на кнопки
    остановки службы, удалите данные или перезагрузите компьютер.

!!! example "Кнопка, которая запрашивает перед запуском"

    ```yaml title="Stop nginx button"
    - name: Stop nginx
      type: button
      function: command
      command: "systemctl stop nginx"
      confirm: true
    ```
