# :material-function: تابع

چیزی که با لمس یک [دکمه](button.md) اجرا می‌شود. یک [تابع](function.md)
چند [پارامتر](parameter.md) را می‌گیرد و آن‌ها را به فرمان شِل تبدیل می‌کند.

دو نوع تابع وجود دارد:

- **توابع توکار** همراه برنامه ارائه می‌شوند (`command` و `script`). شما
  آن‌ها را نمی‌سازید.
- **توابع سفارشی** توابع بیشتری هستند که به‌شکل فایل‌های YAML در
  `function_directory` تعریف می‌کنید.

هنگامی که دکمه‌ای را لمس می‌کنید، ربات تابع را پیدا می‌کند، مقادیر روی دکمه
را در آن قرار می‌دهد و نتیجه را در [Shell](shell.md) اجرا می‌کند.

!!! example "دکمه‌ای که از تابع توکار `command` استفاده می‌کند"

    ```yaml title="دکمهٔ زمان فعالیت"
    - name: Uptime
      type: button
      function: command
      command: "uptime"
    ```

## پیکربندی

برای `function_directory` و فیلدهای دکمه که به توابع ارجاع می‌دهند،
[پیکربندی](../configuration.md) را ببینید.
