# :material-help-circle-outline: تأیید

یک مرحلهٔ اختیاری «مطمئن هستید؟» پیش از اجرای [دکمه](button.md) که با
`confirm: true` فعال می‌شود. برای کارهای مخرب مناسب است.

ربات با پیام (`Confirm: … ?`) و گزینه‌های Yes / Cancel به‌همراه Home (و
هنگامی که داخل دسته هستید، Back) سؤال می‌کند. اگر Run Command فعال باشد، آن
دکمه نیز در صفحهٔ تأیید باقی می‌ماند. تا زمانی که Yes را نزنید چیزی اجرا
نمی‌شود؛ Cancel، Home و Back همگی فرمان را دست‌نخورده رها می‌کنند.

این پیام پس از مدتی منقضی می‌شود (پیش‌فرض ۵ دقیقه). مدت آن را با
`confirm_ttl` در [فایل پیکربندی](config-file.md) تغییر دهید. اگر منقضی شد،
برای دریافت پیام تازه دوباره دکمه را بزنید.

!!! warning "برای هر کار برگشت‌ناپذیر از آن استفاده کنید"

    یک کلید منو روی گوشی تنها یک لمس فاصله دارد و همهٔ کاربران مجاز منوی
    یکسانی می‌بینند. برای دکمه‌هایی که سرویسی را متوقف می‌کنند، داده‌ای را
    حذف می‌کنند یا دستگاه را دوباره راه‌اندازی می‌کنند، `confirm: true`
    بگذارید.

!!! example "دکمه‌ای که پیش از اجرا سؤال می‌کند"

    ```yaml title="دکمهٔ توقف nginx"
    - name: Stop nginx
      type: button
      function: command
      command: "systemctl stop nginx"
      confirm: true
    ```

## پیکربندی

برای `confirm` روی دکمه‌ها و `confirm_ttl` سراسری،
[پیکربندی](../configuration.md) را ببینید.
