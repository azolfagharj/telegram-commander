# :material-shield-lock: کاربران مجاز

فهرست حساب‌های تلگرامی که با `user_id` عددی یا `@username` اجازهٔ استفاده
از ربات را دارند. دسترسی همهٔ افراد دیگر رد می‌شود.

کاربران غیرمجاز پیامی شامل `user_id` و `username` خود دریافت می‌کنند تا
بتوانند از مدیر درخواست دسترسی کنند. بار نخست شناسهٔ خودتان را نیز همین‌گونه
پیدا می‌کنید؛ [اجرا در CLI ← گام ۵](../installation/download-and-run.md#step-5-find-your-user-id-if-needed)
را ببینید.

همین پیام راه افزودن یک نفر نیز هست. از فرد جدید بخواهید هر پیامی برای ربات
بفرستد، شناسه‌ای را که ربات پاسخ می‌دهد کپی کند، آن شناسه را به
`allowed_users` بیفزایید و ربات را دوباره راه‌اندازی کنید. دفعهٔ بعد که پیام
بدهد، به‌جای پاسخ رد دسترسی، منو را می‌بیند.

!!! warning "همهٔ افراد فهرست، منوی یکسانی دارند"

    مجوز جداگانه‌ای برای هر کاربر وجود ندارد. هر کسی که اضافه کنید می‌تواند
    همهٔ دکمه‌های تعریف‌شده را لمس کند؛ پس فهرست را به افرادی محدود کنید که
    برای دسترسی به خود دستگاه به آن‌ها اعتماد دارید.

!!! example "دو حساب مجاز به استفاده از ربات"

    ```yaml title="telegram section of config.yaml"
    telegram:
      allowed_users:
        - "123456789"
        - "@alice"
    ```
