# :material-console: `command`

`command` یک [تابع توکار](../index.md#built-in-functions) است. این تابع یک
فرمان شِل را دقیقاً همان‌گونه که روی دکمه نوشته‌اید اجرا می‌کند.

| پارامتر | الزامی | پیش‌فرض | معنی |
|-----------|----------|---------|---------|
| `command` | بله | — | فرمان شِل برای اجرا |

!!! example "اجرای یک فرمان همان‌گونه که نوشته شده"

    ```yaml title="دکمهٔ نمایش کرنل"
    - name: Show kernel
      type: button
      function: command
      command: "uname -a"
    ```

## Pipe و فرمان‌های زنجیره‌ای

فرمان‌ها از طریق [`/bin/bash -c`](../../concepts/shell.md) اجرا می‌شوند؛
بنابراین pipe، تغییر مسیر و `&&` همگی در یک مقدار `command` کار می‌کنند.

!!! example "Pipe درون فرمان‌ها کار می‌کند"

    ```yaml title="دکمهٔ پردازش‌های برتر"
    - name: Top processes
      type: button
      function: command
      command: "ps aux --sort=-%mem | head -n 10"
    ```

!!! tip "برای فرمان‌های تکراری از تابع سفارشی استفاده کنید"

    اگر چند دکمه ساختار فرمان یکسانی را تکرار می‌کنند، یک تابع سفارشی بسازید
    و در هر دکمه فقط مقادیر متفاوت را بدهید. نام پارامترهای سفارشی مانند
    `url` یا `host` را می‌توانید مستقیم روی آن دکمه‌ها بنویسید.
