# :material-console: `command`

`command` — это [встроенная функция ](../index.md#built-in-functions). Он
запускает одну команду оболочки именно так, как вы написали на кнопке.

| Параметр | Требуется | По умолчанию | Значение |
|-----------|----------|---------|---------|
| `command` | да | — | Команда оболочки для запуска |

!!! example "Выполните одну команду, как написано"

    ```yaml title="Show kernel button"
    - name: Show kernel
      type: button
      function: command
      command: "uname -a"
    ```

## Конвейеры и связанные команды

Команды выполняются через [`/bin/bash -c`](../../concepts/shell.md), поэтому
каналы, перенаправления и `&&` работают внутри одного значения `command`.

!!! example "Пайпы работают внутри команд"

    ```yaml title="Top processes button"
    - name: Top processes
      type: button
      function: command
      command: "ps aux --sort=-%mem | head -n 10"
    ```

!!! tip "Использовать пользовательскую функцию для повторяющихся команд"

    Если несколько кнопок повторяют одну и ту же форму команды, создайте
    собственную функцию. и присваивайте каждой кнопке только те значения,
    которые меняются. Имена пользовательских параметров например, `url` или
    `host`, можно написать непосредственно на этих кнопках.
