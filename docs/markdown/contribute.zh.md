# :material-handshake-outline: 想为 Telegram Commander 出一份力吗？ { #want-to-contribute-to-telegram-commander }

Telegram Commander 还处在早期阶段。即使不写代码，你也有多种方式可以帮忙。

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __报告问题__

    ---

    某个功能无法使用，或者与本指南所写的不一致。

    [:octicons-arrow-right-24: 提交 issue](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __提出新功能__

    ---

    你有一个能让机器人对大家都更好用的想法。

    [:octicons-arrow-right-24: 分享想法](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __提问__

    ---

    安装、配置或运行中有不清楚的地方。

    [:octicons-arrow-right-24: 寻求帮助](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __展示与分享__

    ---

    你做了值得展示的菜单、脚本或配置。

    [:octicons-arrow-right-24: 展示你的配置](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

动手之前，请先看看已有的内容。也许有人报告过同样的问题，或问过同样的疑问。

## :material-code-braces: 代码贡献 { #code-contributions }

!!! warning "目前不接受 pull request"

    Telegram Commander 仍在建立自己的贡献流程。随着项目成长，代码贡献和
    pull request 可能会逐步开放。

在此之前，一份清楚的问题报告或描述完整的想法，和代码一样有价值。关注这个仓库，
就能知道什么时候有变化。

## :material-shield-lock-outline: 安全问题 { #security }

请不要在公开的 issue 或讨论中报告安全问题。

请使用仓库 Security 标签页中的 **Report a vulnerability**。在修复之前，报告都会
保持私密。

<div style="text-align: center" markdown="span">
[报告安全漏洞 :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: 支持这个项目 { #support-the-project }

Telegram Commander 是免费的，将来也会一直免费。如果它为你节省了时间，你也愿意回馈，
捐赠可以帮助这项工作继续下去。
