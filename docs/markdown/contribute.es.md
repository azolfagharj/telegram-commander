# :material-handshake-outline: ¿Quieres contribuir a Telegram Commander? { #want-to-contribute-to-telegram-commander }

Telegram Commander está aún en sus comienzos. Hay varias formas de ayudar,
incluso sin escribir código.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __Informar de un fallo__

    ---

    Algo no funciona, o no funciona como dice esta guía.

    [:octicons-arrow-right-24: Abrir una incidencia](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __Proponer una función__

    ---

    Tienes una idea que haría mejor el bot para todos.

    [:octicons-arrow-right-24: Compartir tu idea](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __Hacer una pregunta__

    ---

    Algo de la instalación, la configuración o la ejecución no está claro.

    [:octicons-arrow-right-24: Pedir ayuda](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __Enseñar lo que hiciste__

    ---

    Has creado un menú, un script o una configuración que merece verse.

    [:octicons-arrow-right-24: Enseñar tu configuración](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

Antes de escribir, mira lo que ya hay. Puede que alguien haya informado del
mismo problema o hecho la misma pregunta.

## :material-code-braces: Contribuciones de código { #code-contributions }

!!! warning "Las pull requests están cerradas por ahora"

    Telegram Commander todavía está definiendo su forma de recibir
    contribuciones. Las contribuciones de código y las pull requests podrán
    abrirse poco a poco a medida que el proyecto crezca.

Mientras tanto, un informe de fallo claro o una idea bien explicada ayuda tanto
como el código. Sigue el repositorio para ver cuándo cambia esto.

## :material-shield-lock-outline: Seguridad { #security }

No informes de un problema de seguridad en una incidencia o una discusión
públicas.

Usa **Report a vulnerability** en la pestaña Security del repositorio. El aviso
queda en privado hasta que haya una solución.

<div style="text-align: center" markdown="span">
[Informar de una vulnerabilidad :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: Apoyar el proyecto { #support-the-project }

Telegram Commander es gratuito y lo seguirá siendo. Si te ahorra tiempo y
quieres devolver algo, una donación ayuda a seguir con el trabajo.

<div style="text-align: center" markdown="span">
[Donar :material-hand-heart-outline:](https://azolfagharj.github.io/donate/){ .md-button .md-button--primary }
</div>
