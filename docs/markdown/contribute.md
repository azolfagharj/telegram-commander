# :material-handshake-outline: Want to contribute to Telegram Commander?

Telegram Commander is still in its early stage. There are several ways you can
help, even without writing code.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __Report a bug__

    ---

    Something does not work, or does not work the way this guide says.

    [:octicons-arrow-right-24: Open an issue](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __Suggest a feature__

    ---

    You have an idea that would make the bot better for everyone.

    [:octicons-arrow-right-24: Share your idea](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __Ask a question__

    ---

    Something about installing, configuring, or running is unclear.

    [:octicons-arrow-right-24: Ask for help](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __Show and tell__

    ---

    You built a menu, a script, or a setup worth showing to others.

    [:octicons-arrow-right-24: Show your setup](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

Before you write, please look through what is already there. Someone may have
reported the same problem or asked the same question.

## :material-code-braces: Code contributions

!!! warning "Pull requests are currently closed"

    Telegram Commander is still establishing its contribution workflow. Code
    contributions and pull requests may gradually open as the project grows.

Until then, a clear bug report or a well described idea helps just as much as
code. Watch the repository to see when this changes.

## :material-shield-lock-outline: Security

Please do not report a security problem in a public issue or discussion.

Use **Report a vulnerability** on the repository's Security tab. The report
stays private until there is a fix.

<div style="text-align: center" markdown="span">
[Report a vulnerability :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: Support the project

Telegram Commander is free and stays free. If it saves you time and you would
like to give something back, a donation helps keep the work going.

<div style="text-align: center" markdown="span">
[Donate :material-hand-heart-outline:](https://azolfagharj.github.io/donate/){ .md-button .md-button--primary }
