# :material-handshake-outline: می‌خواهید به Telegram Commander کمک کنید؟ { #want-to-contribute-to-telegram-commander }

Telegram Commander هنوز در آغاز راه است. راه‌های مختلفی برای کمک هست، حتی بدون
اینکه کدی بنویسید.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __گزارش ایراد__

    ---

    چیزی کار نمی‌کند، یا آن‌طور که در این راهنما نوشته شده کار نمی‌کند.

    [:octicons-arrow-left-24: ثبت ایشو](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __پیشنهاد قابلیت__

    ---

    ایده‌ای دارید که ربات را برای همه بهتر می‌کند.

    [:octicons-arrow-left-24: ایده‌تان را بگویید](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __پرسیدن سؤال__

    ---

    جایی از نصب، پیکربندی یا اجرا برایتان روشن نیست.

    [:octicons-arrow-left-24: درخواست کمک](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __نشان دادن کارتان__

    ---

    منو، اسکریپت یا تنظیماتی ساخته‌اید که دیدنش برای بقیه ارزش دارد.

    [:octicons-arrow-left-24: تنظیماتتان را نشان دهید](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

پیش از نوشتن، نگاهی به موارد موجود بیندازید. شاید کسی همین مشکل را گزارش کرده یا
همین سؤال را پرسیده باشد.

## :material-code-braces: مشارکت در کد { #code-contributions }

!!! warning "فعلاً pull request بسته است"

    Telegram Commander هنوز در حال شکل دادن به روند مشارکت خود است. با رشد
    پروژه، مشارکت در کد و pull request کم‌کم باز می‌شود.

تا آن زمان، یک گزارش ایراد روشن یا ایده‌ای که خوب توضیح داده شده، به‌اندازهٔ کد
کمک می‌کند. مخزن را دنبال کنید تا ببینید این موضوع کی تغییر می‌کند.

## :material-shield-lock-outline: امنیت { #security }

لطفاً مشکل امنیتی را در ایشو یا گفتگوی عمومی گزارش نکنید.

از **Report a vulnerability** در زبانهٔ Security مخزن استفاده کنید. گزارش تا
زمانی که رفع نشود، خصوصی می‌ماند.

<div style="text-align: center" markdown="span">
[گزارش آسیب‌پذیری :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

دوست دارید جبران کنید، کمک مالی به ادامهٔ کار کمک می‌کند.
