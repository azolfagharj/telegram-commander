# :material-handshake-outline: Envie de contribuer à Telegram Commander ? { #want-to-contribute-to-telegram-commander }

Telegram Commander en est encore à ses débuts. Il y a plusieurs façons d'aider,
même sans écrire de code.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __Signaler un bug__

    ---

    Quelque chose ne marche pas, ou pas comme ce guide l'indique.

    [:octicons-arrow-right-24: Ouvrir un ticket](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __Proposer une fonction__

    ---

    Vous avez une idée qui rendrait le bot meilleur pour tout le monde.

    [:octicons-arrow-right-24: Partager votre idée](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __Poser une question__

    ---

    Un point de l'installation, de la configuration ou de l'exécution reste flou.

    [:octicons-arrow-right-24: Demander de l'aide](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __Montrer et raconter__

    ---

    Vous avez créé un menu, un script ou une configuration qui mérite d'être vue.

    [:octicons-arrow-right-24: Montrer votre configuration](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

Avant d'écrire, regardez ce qui existe déjà. Quelqu'un a peut-être signalé le
même problème ou posé la même question.

## :material-code-braces: Contributions au code { #code-contributions }

!!! warning "Les pull requests sont fermées pour le moment"

    Telegram Commander met encore en place son processus de contribution. Les
    contributions au code et les pull requests pourront s'ouvrir peu à peu à
    mesure que le projet grandit.

En attendant, un rapport de bug clair ou une idée bien décrite aide autant que
du code. Suivez le dépôt pour voir quand cela changera.

## :material-shield-lock-outline: Sécurité { #security }

Merci de ne pas signaler un problème de sécurité dans un ticket ou une
discussion publics.

Utilisez **Report a vulnerability** dans l'onglet Security du dépôt. Le
signalement reste privé jusqu'à ce qu'un correctif existe.

<div style="text-align: center" markdown="span">
[Signaler une faille :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: Soutenir le projet { #support-the-project }

Telegram Commander est gratuit et le restera. S'il vous fait gagner du temps et
que vous souhaitez rendre la pareille, un don aide à poursuivre le travail.

<div style="text-align: center" markdown="span">
[Faire un don :material-hand-heart-outline:](https://azolfagharj.github.io/donate/){ .md-button .md-button--primary }
</div>
