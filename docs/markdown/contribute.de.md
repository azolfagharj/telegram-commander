# :material-handshake-outline: Möchten Sie bei Telegram Commander mitmachen? { #want-to-contribute-to-telegram-commander }

Telegram Commander steht noch am Anfang. Es gibt mehrere Wege zu helfen, auch
ohne Code zu schreiben.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __Fehler melden__

    ---

    Etwas funktioniert nicht oder nicht so, wie es hier beschrieben ist.

    [:octicons-arrow-right-24: Issue eröffnen](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __Funktion vorschlagen__

    ---

    Sie haben eine Idee, die den Bot für alle besser macht.

    [:octicons-arrow-right-24: Idee teilen](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __Frage stellen__

    ---

    Etwas beim Installieren, Einrichten oder Ausführen ist unklar.

    [:octicons-arrow-right-24: Um Hilfe bitten](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __Zeigen und erzählen__

    ---

    Sie haben ein Menü, ein Skript oder ein Setup gebaut, das andere sehen sollten.

    [:octicons-arrow-right-24: Setup zeigen](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

Sehen Sie bitte vorher nach, was es schon gibt. Vielleicht hat jemand dasselbe
Problem gemeldet oder dieselbe Frage gestellt.

## :material-code-braces: Beiträge im Code { #code-contributions }

!!! warning "Pull Requests sind derzeit geschlossen"

    Telegram Commander baut seinen Ablauf für Beiträge gerade erst auf.
    Codebeiträge und Pull Requests werden sich mit dem Projekt nach und nach
    öffnen.

Bis dahin hilft ein klarer Fehlerbericht oder eine gut beschriebene Idee genauso
viel wie Code. Beobachten Sie das Repository, um zu sehen, wann sich das ändert.

## :material-shield-lock-outline: Sicherheit { #security }

Bitte melden Sie ein Sicherheitsproblem nicht in einem öffentlichen Issue oder
einer öffentlichen Diskussion.

Nutzen Sie **Report a vulnerability** im Security-Tab des Repositorys. Die
Meldung bleibt privat, bis es eine Lösung gibt.

<div style="text-align: center" markdown="span">
[Sicherheitslücke melden :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: Das Projekt unterstützen { #support-the-project }

Telegram Commander ist kostenlos und bleibt es. Wenn es Ihnen Zeit spart und Sie
etwas zurückgeben möchten, hilft eine Spende, die Arbeit fortzuführen.

<div style="text-align: center" markdown="span">
[Spenden :material-hand-heart-outline:](https://azolfagharj.github.io/donate/){ .md-button .md-button--primary }
</div>
