# :material-handshake-outline: Хотите помочь Telegram Commander? { #want-to-contribute-to-telegram-commander }

Telegram Commander ещё в самом начале пути. Помочь можно по-разному, даже не
написав ни строчки кода.

<div class="grid cards cols-4 center-title" markdown>

-   :material-bug-outline:{ .lg .middle } __Сообщить об ошибке__

    ---

    Что-то не работает или работает не так, как описано в этом руководстве.

    [:octicons-arrow-right-24: Создать issue](https://github.com/azolfagharj/telegram-commander/issues/new?template=bug_report.md)

-   :material-lightbulb-on-outline:{ .lg .middle } __Предложить возможность__

    ---

    У вас есть идея, которая сделает бота лучше для всех.

    [:octicons-arrow-right-24: Поделиться идеей](https://github.com/azolfagharj/telegram-commander/discussions/categories/ideas-feature-requests)

-   :material-help-circle-outline:{ .lg .middle } __Задать вопрос__

    ---

    Что-то в установке, настройке или запуске осталось непонятным.

    [:octicons-arrow-right-24: Попросить помощи](https://github.com/azolfagharj/telegram-commander/discussions/categories/questions-help)

-   :material-hand-wave-outline:{ .lg .middle } __Показать свою работу__

    ---

    Вы собрали меню, скрипт или настройку, которую стоит показать другим.

    [:octicons-arrow-right-24: Показать настройку](https://github.com/azolfagharj/telegram-commander/discussions/categories/show-tell)

</div>

Прежде чем писать, посмотрите, что уже есть. Возможно, кто-то уже сообщил о той
же проблеме или задал тот же вопрос.

## :material-code-braces: Вклад в код { #code-contributions }

!!! warning "Pull request'ы сейчас закрыты"

    Telegram Commander ещё выстраивает порядок приёма изменений. Вклад в код и
    pull request'ы могут постепенно открыться по мере роста проекта.

А пока понятный отчёт об ошибке или хорошо описанная идея помогают не меньше,
чем код. Следите за репозиторием, чтобы узнать, когда это изменится.

## :material-shield-lock-outline: Безопасность { #security }

Пожалуйста, не сообщайте о проблеме безопасности в публичном issue или
обсуждении.

Используйте **Report a vulnerability** на вкладке Security репозитория.
Сообщение остаётся закрытым, пока не появится исправление.

<div style="text-align: center" markdown="span">
[Сообщить об уязвимости :material-shield-alert-outline:](https://github.com/azolfagharj/telegram-commander/security){ .md-button }
</div>

## :material-heart-outline: Поддержать проект { #support-the-project }

вы хотите отблагодарить, пожертвование помогает продолжать работу.
