# Telegram Commander

Telegram Commander ist ein kostenloser Open-Source-Telegram-Bot für
Linux-Server. Sie beschreiben ein Schaltflächenmenü in einer einzigen
YAML-Konfigurationsdatei; jede Schaltfläche enthält einen Shell-Befehl. Wenn
ein zugelassenes Telegram-Konto eine Schaltfläche antippt, führt der Bot den
Befehl auf dem Rechner aus und sendet die Ausgabe zurück an den Chat. Sie
können Schaltflächen in Kategorien gruppieren, vor riskanten Aktionen eine
Bestätigung anfordern, den Zugriff auf ausgewählte Benutzer beschränken und
jede Ausführung in einem Audit-Protokoll erfassen. Der Bot lauscht nicht auf
eingehende Verbindungen, sondern verbindet sich ausschließlich ausgehend mit
Telegram. Deshalb muss auf dem Server kein Port geöffnet werden. Es ist weder
Programmierung noch ein abzusicherndes Webpanel erforderlich.
