# Changelog

## Changed
- The GitHub README now shows a short YAML example next to the opening
  text, so you can see how a button is defined before you install.
- The GitHub README now says how Telegram Commander differs from opening
  an SSH session for the same routine work.
- The GitHub README now tells you to leave a placeholder in `allowed_users`
  when you do not know your user id yet, matching how the bot actually
  starts.
- A few GitHub README sentences are clearer: there is no web panel to
  manage, and Telegram is used to manage the server, not to start it.
