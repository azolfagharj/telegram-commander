# Changelog

## Added
- Docs images open in a lightbox when you click them
- The docs home page now shows what the bot does at a glance, with screenshots and links to the page you need next
- New docs section explaining that your commands run one at a time, so a second tap waits for the first to finish
- The Button page now explains every field, what happens after you tap, and ready-made examples for services, logs, and scripts

## Changed
- The Run Command button is now labeled `$ >_ Run Command`
- Home page screenshots are the same size and sit side by side in one row
- Example configs group System into Resources, Processes, Storage, and APT, and add more Network buttons
- Docs pages load without a full refresh and have a back-to-top button and links to the previous and next page
- The Allowed users, Confirmation, Audit log, and How the bot connects pages explain when and why to use each
- Docs pages are easier to scan with labelled examples, clearer callouts, and consistent icons
- Docs pages now have section tabs at the top, smaller cards, and labelled code samples with titles
- The docs side menu now lists every page, not only the pages of the open tab, and each page has its own icon
- Docs now match how a button passes values: only command, path, and args on the button
- Each docs page has its own title and description for search results
