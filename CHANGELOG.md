# Changelog

## Added
- A button can supply any value its function asks for, as a key on the button itself (for example `url` on `curl-url`)

## Changed
- The left menu now lists the pages of the section you are in, and the section tabs stay pinned at the top while you scroll. Groups in the menu are plain labels, and only real pages show an icon
- The Functions guide is now split into short focused pages, grouped in the menu as Built-in, Release pack, and Write your own. The Functions page itself covers what a function is, how a button passes values, and where each kind of function comes from
- The Configuration page now shows its icon in the menu and its own summary in search results
- Docs open in dark mode by default, with indigo and black colours; you can still switch to light mode with the same sun and moon icons

## Fixed
- Values other than `command`, `path`, and `args` on a button are no longer ignored
