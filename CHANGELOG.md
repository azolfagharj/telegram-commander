# Changelog

## Added
- A small Home button is now always pinned under the message box, so you can get back to the menu even without scrolling.

## Changed
- Every menu screen (menu, confirmation, command result) is now sent as its own new message, and the previous screen is removed right after. This fixes button text sometimes looking cut off or overlapping on Android.
- Menu items are now shown one per row (full width) by default instead of two per row, to test whether this avoids button text getting cut off on Android.
