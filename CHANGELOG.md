# Changelog

## Added
- Documentation is now available in French from the language menu.
- Documentation is also available in Spanish, Russian and Simplified Chinese from the language menu.
- Documentation is now available in Persian from the language menu.

## Changed
- The two tabs at the top of the documentation, Home and Documentation, now
  show a small picture next to their name.
- The documentation home page now has a small line under the opening text with a flag link to the same page in every other language.
- Every documentation page now ends with a small language row in the footer: the word for "language" in the page language, then every language with its flag.
- The language button at the top of the documentation is now the translate icon, so it is clearer that it changes the language.
- The GitHub README now has a short full-documentation section, with a flag link for each language, before the list of what you can do with the bot.
- The GitHub README now matches the documentation home page: what you can do with the bot, why to use it, and the old Features list is gone so the same points are not repeated.
- The language menu now shows two languages per row, each with a small flag before its name, so the whole list fits without scrolling.
- Persian pages are now shown in the Vazir font, with a lighter or heavier cut depending on where the text sits: page text, titles, menus and small print. Code stays in the same monospace font as the other languages.

## Fixed
- Config examples in German and Persian now keep button and category names in
  English, matching the copyable examples in every other language.
- Comments in config examples now use the page language in German, French,
  Spanish, Russian and Simplified Chinese. Persian examples use short English
  comments so their left-to-right code stays easy to read.
- Icons on Persian pages now sit on the middle of the line next to their text, instead of floating too high, on buttons, links, headings and cards.
- Persian pages now point the right way: the arrows on buttons and card links, the pointing hand, the small arrow between the page path names, and the step numbers and card icons that used to sit on the wrong side.
- Translated docs now match the English pages: missing details, mixed-language captions, and unclear wording were corrected in German, French, Spanish, Russian and Simplified Chinese
