# Changelog

## Changed

- The bot now keeps one menu message in the chat and updates it as you tap, instead of sending a new message each time
- Back, Prev, and Next now use different icons so their text does not get cut off on some phones

## Fixed

- After you type `/start` (or any other command/text) once you have already used the menu, the new menu now shows up as the newest message in the chat instead of appearing above what you typed
- Some icons on categories and buttons could make the button text spill outside the button on Android; icons are now shown in a safer form
